# controle-de-estoque-web

### **Autor:** Alisson Santos

Este projeto tem como objetivo desenvolver uma aplicação web responsiva para controle de estoque e registro de vendas, permitindo o gerenciamento de produtos, acompanhamento de movimentações e organização de dados de forma simples e eficiente.

O frontend da aplicação será desenvolvido com HTML, CSS e JavaScript, utilizando um framework CSS para responsividade. O backend será simulado por meio de uma API Fake utilizando JSON Server.
